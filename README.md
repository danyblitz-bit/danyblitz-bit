# danyblitz-bit

Indie developer building practical, local-first developer tools.

## Tools

| Tool | What it does | Stack |
|------|--------------|-------|
| [data-scraper](https://github.com/danyblitz-bit/data-scraper) | High-performance desktop web scraper with native Windows GUI | Rust, eframe |
| [site-auditor](https://github.com/danyblitz-bit/site-auditor) | Website health check: SEO, performance, broken links in one command | Python |
| [pdf-metaclean](https://github.com/danyblitz-bit/pdf-metaclean) | Strip sensitive metadata from PDFs before sharing | Python |

All projects are MIT licensed and free to use. Built for speed, privacy, and no lock-in.
